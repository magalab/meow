# Changelog

## 0.1.2 — 2026-10-15

- Added launcher filters for all results, applications, clipboard history, and commands.
- Added explicit calculator mode with `=` prefix, arithmetic operators, percentages, and parentheses.
- Made the empty launcher compact and adjusted result height without moving the top edge during search.
- Fixed runtime English/Simplified Chinese switching for hosted SwiftUI panels and window titles.
- Improved launcher sizing and clamped its position to the active screen's visible area.
- Added calculator and runtime localization tests.
